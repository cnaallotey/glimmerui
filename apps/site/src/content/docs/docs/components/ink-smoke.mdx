A plume of smoke rises from the bottom of the element, widening and curling as it climbs. Hovering moves its source to the pointer, and it drifts after the pointer the way real smoke lags behind a moving source. Use it as a background: children sit above it.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `color` | `string` | `"#e9e8ee"` | Smoke color, as a hex value. For ink in water, try a dark color on a light background. |
| `background` | `string` | `"#0e0d12"` | Color behind the smoke, as a hex value. |
| `speed` | `number` | `1` | How fast the smoke rises. `0` holds it still. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- The source eases over to the pointer on hover and back to the bottom center when the pointer leaves.
- Without WebGL, the element gets a soft CSS glow of the smoke color rising from the bottom.
- The canvas is hidden from assistive technology. Children stay accessible.
