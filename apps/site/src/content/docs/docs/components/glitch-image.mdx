import { Tabs, TabItem } from "@astrojs/starlight/components";

Shows an image that looks normal at rest. On hover it glitches: horizontal bands jump sideways, the color channels split apart and faint scanlines appear. The glitch re-rolls about twelve times a second and is strongest in the rows around the pointer.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image or video URL. Must be same origin or served with CORS headers. See [Images and video](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `strength` | `number` | `1` | How hard the image glitches, from 0 to 2. |
| `video` | `boolean` | `false` | Set it when `src` is a video whose URL doesn't end in a video extension. See [Images and video](/docs/guides/images/#video). |
| `paused` | `boolean` | `false` | Holds a video on its current frame. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- The glitch starts and stops quickly, in about a fifth of a second.
- On touch screens, a tap starts the glitch and another tap stops it.
- With reduced motion, the glitch doesn't flicker on its own. It only changes as the pointer moves.
- Without WebGL, the element shows the plain image as a `background-image`.
