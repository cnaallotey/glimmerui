Fills text with three colors flowing through each other, with a highlight that follows the pointer. The text itself stays in the page as real text: it sizes the element, can be selected and copied, and is read by screen readers. The effect draws a matching copy behind it.

## Usage

`ShaderText` renders a `<span>`, so put it inside a heading for headlines. It uses the font, size and weight it inherits.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `text` | `string` | required | The text. Use `\n` for line breaks; lines don't wrap on their own. |
| `colors` | `[string, string, string]` | `["#3b1d8f", "#e0457b", "#f9b44c"]` | Three hex colors that flow through the letters. |
| `speed` | `number` | `1` | How fast the colors flow. `0` holds them still. |

The component also takes any `span` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- Lines don't wrap, so the text keeps one shape on every screen. Use `\n` to break lines, and size the text with `clamp()` so it fits narrow screens.
- Web fonts are picked up once they load.
- Selected text shows the browser's selection highlight over the effect.
- Without WebGL, the text gets a CSS gradient clipped to the letters.
