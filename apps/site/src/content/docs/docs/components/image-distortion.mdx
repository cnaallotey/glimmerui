Shows an image that fills its element. On hover, ripples spread out from the pointer and split the image's color channels as they pass.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image URL. Must be same origin or served with CORS headers. See [Images and CORS](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `strength` | `number` | `1` | Strength of the ripple and color split. `0` turns the effect off. |

The component also takes any `div` attribute. See [React](/docs/react/) and [Vue](/docs/vue/).

## Behavior

- The image is cropped to cover the element, like `object-fit: cover`.
- Changing `src` keeps the current image on screen until the new one has loaded.
- Ripples only appear while a mouse or pen hovers. Touch has no hover, so on touch screens the image stays still.
- Without WebGL, the image is shown as a plain `background-image` that covers the element.
