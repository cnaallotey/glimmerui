A glowing grid floor stretches to the horizon in perspective and rolls toward you, fading into a warm horizon glow. Hovering presses a dip into the floor under the pointer. Use it as a background: children sit above it.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `color` | `string` | `"#e0457b"` | Grid line color, as a hex value. |
| `glow` | `string` | `"#f9b44c"` | Color of the glow along the horizon, as a hex value. |
| `background` | `string` | `"#0e0d12"` | Sky and floor color, as a hex value. |
| `speed` | `number` | `1` | How fast the grid rolls toward you. `0` holds it still. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- Grid lines stay the same width in pixels from the foreground to the horizon, and fade with distance.
- The horizon sits just below the middle of the element.
- Without WebGL, the element gets a CSS horizon glow and vertical lines in the same colors.
- The canvas is hidden from assistive technology. Children stay accessible.
