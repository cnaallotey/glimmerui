Draws an image in just two colors, like an early computer screen: every dot is ink or paper, chosen by comparing the image's brightness against a repeating 8×8 pattern of thresholds. Around the pointer, the full-color image shows through.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image URL. Must be same origin or served with CORS headers. See [Images and CORS](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `pixel` | `number` | `2` | Size of each dither dot, in CSS pixels. |
| `ink` | `string` | `"#0e0d12"` | Dark color, as a hex value. |
| `paper` | `string` | `"#fafafa"` | Light color, as a hex value. |
| `radius` | `number` | `140` | Radius of the full-color area around the pointer, in CSS pixels. |

The component also takes any `div` attribute. See [React](/docs/react/) and [Vue](/docs/vue/).

## Behavior

- Photos with smooth gradients dither best. Large flat areas turn into even patterns.
- On touch screens, a tap opens the full-color area around the tapped point, and another tap closes it.
- Without WebGL, the element shows the plain image as a `background-image`.
