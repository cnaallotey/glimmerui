Shows an image as a mosaic of large blocks. Around the pointer the blocks get finer in steps, halving in size each ring, until the image is sharp at the center.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image or video URL. Must be same origin or served with CORS headers. See [Images and video](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `block` | `number` | `32` | Block size away from the pointer, in CSS pixels. Powers of two (8, 16, 32, 64) give the neatest steps. |
| `radius` | `number` | `180` | Radius of the sharp area around the pointer, in CSS pixels. |
| `video` | `boolean` | `false` | Set it when `src` is a video whose URL doesn't end in a video extension. See [Images and video](/docs/guides/images/#video). |
| `paused` | `boolean` | `false` | Holds a video on its current frame. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- Block sizes snap to powers of two, so each ring of blocks lines up with the next.
- The image is cropped to cover the element, like `object-fit: cover`.
- On touch screens, a tap sharpens the image around the tapped point, and another tap returns it to a mosaic.
- Without WebGL, the element shows the plain image as a `background-image`.
