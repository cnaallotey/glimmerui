Draws an image the way a newspaper prints it: one dot per cell on a 45 degree grid, larger where the image is darker. Around the pointer, the dots give way to the full-color image.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image or video URL. Must be same origin or served with CORS headers. See [Images and video](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `cell` | `number` | `8` | Distance between dot centers, in CSS pixels. Smaller cells keep more detail. |
| `ink` | `string` | `"#0e0d12"` | Dot color, as a hex value. |
| `paper` | `string` | `"#fafafa"` | Color behind the dots, as a hex value. |
| `radius` | `number` | `140` | Radius of the full-color area around the pointer, in CSS pixels. |
| `video` | `boolean` | `false` | Set it when `src` is a video whose URL doesn't end in a video extension. See [Images and video](/docs/guides/images/#video). |
| `paused` | `boolean` | `false` | Holds a video on its current frame. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- Images with a wide range of light and dark, such as photos, make the best halftones. Flat graphics turn into even fields of dots.
- The image is cropped to cover the element, like `object-fit: cover`.
- On touch screens, a tap opens the full-color area around the tapped point, and another tap closes it.
- Without WebGL, the element shows the plain image as a `background-image`.
