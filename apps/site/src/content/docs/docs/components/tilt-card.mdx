An image card that tilts toward the pointer in real 3D perspective, with a glare that follows the pointer and anti-aliased rounded corners.

<TiltCardDemo client:visible />

## Usage

<Tabs syncKey="framework">

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `src` | `string` | required | Image or video URL. Must be same origin or served with CORS headers. See [Images and video](/docs/guides/images/). |
| `alt` | `string` | required | Describes the image for screen readers. |
| `maxTilt` | `number` | `0.4` | Largest tilt, in radians. `0.4` is about 23 degrees. |
| `radius` | `number` | `20` | Corner radius in CSS pixels. |
| `glare` | `number` | `1` | Strength of the glare, from 0 to 1. |
| `video` | `boolean` | `false` | Set it when `src` is a video whose URL doesn't end in a video extension. See [Images and video](/docs/guides/images/#video). |
| `paused` | `boolean` | `false` | Holds a video on its current frame. |

The component also takes any `div` attribute. See [React](/docs/react/), [Vue](/docs/vue/) and [Svelte](/docs/svelte/).

## Behavior

- The card is drawn at about 70% of the element's height so its edges stay inside the element at full tilt. Make the element a little larger than the card you want to see.
- The image is cropped to cover the card.
- Leaving the card lets it settle back to flat.
- Without WebGL, the element shows the image as a `background-image` with the same corner radius.
