`@glimmerui/core` holds the effects with no framework code. The React and Vue components are thin wrappers around it. Use it directly for another framework, or for plain JavaScript.

```bash
npm install @glimmerui/core
```

## Creating an effect

Each function takes an element and options, appends a canvas to the element, and returns a controller.

```ts
import { createTiltCard } from "@glimmerui/core";

const el = document.querySelector<HTMLElement>("#cover")!;
const card = createTiltCard(el, { src: "/cover.jpg", radius: 16 });

el.addEventListener("pointermove", (e) => {
  const r = el.getBoundingClientRect();
  card.setPointer((e.clientX - r.left) / r.width, 1 - (e.clientY - r.top) / r.height);
});
el.addEventListener("pointerenter", (e) => {
  if (e.pointerType !== "touch") card.setHover(1);
});
el.addEventListener("pointerleave", () => {
  card.setHover(0);
  card.setPointer(0.5, 0.5);
});
```

The element needs a size, and should have `position: relative` if you place other content over the canvas.

## Controller methods

| Method | Available on | What it does |
| --- | --- | --- |
| `setPointer(x, y)` | all | Moves the pointer, smoothed with a spring. `x` and `y` run from 0 to 1, with the origin at the **bottom left**. |
| `setIntensity(value)` | `ShaderGradient`, `Aurora` | Animates the pointer's pull to a value from 0 to 1. |
| `setHover(value)` | every component except `ShaderGradient` and `Aurora` | Animates the hover amount from 0 to 1: the ripple, glare, reveal, lens, pointer blob, or the dots' and particles' reaction. |
| `update(options)` | all | Applies new options to the running effect. Pass the full options object: any option you leave out goes back to its default. |
| `destroy()` | all | Stops the effect, frees its GPU resources and removes its canvas. |

`CursorTrail`'s controller has only `update` and `destroy`, since it follows the window's pointer by itself.

Without WebGL, the functions apply the CSS fallback to the element and return a controller whose pointer methods do nothing.

## Your own backgrounds

`createBackground(el, options, spec)` is what the newer backgrounds are built on. Give it a fragment shader and it handles the canvas, resizing, the pointer, hover, reduced motion, pausing offscreen and the CSS fallback. Your shader gets these uniforms for free:

| Uniform | Type | Value |
| --- | --- | --- |
| `uTime` | `float` | Seconds, multiplied by the spec's `speed` |
| `uRes` | `vec2` | Element size in CSS pixels |
| `uPointer` | `vec2` | Pointer position, 0 to 1, origin at the bottom left |
| `uHover` | `float` | Hover amount, 0 to 1 |
| `vUv` | `vec2` (varying) | Position in the element, 0 to 1 |

```ts
import { createBackground } from "@glimmerui/core";

const glow = createBackground(el, { color: [1, 0.3, 0.5] }, {
  fragment: `
    precision highp float;
    uniform vec2 uPointer;
    uniform float uHover;
    uniform vec3 uColor;
    varying vec2 vUv;
    void main() {
      float d = distance(vUv, uPointer);
      gl_FragColor = vec4(uColor * (1.0 - d) * (0.5 + 0.5 * uHover), 1.0);
    }
  `,
  resolve: (o) => o,
  uniforms: (o) => ({ uColor: o.color }),
  fallback: () => "#ff4d80",
});
```

The returned controller has `setPointer`, `setHover`, `update` and `destroy`, like the built-in backgrounds.

## Your own image effects

`createImageEffect(el, options, spec)` does the same for effects on an image. It loads `options.src`, fades it in, and handles the pointer, hover, resizing and the plain-image fallback. Your shader gets `uTex`, `uImgAspect`, `uLoaded`, `uTime`, `uRes`, `uPointer` and `uHover`. To crop the image like `object-fit: cover`, paste the `coverChunk` string from `@glimmerui/core` into your shader and call `coverUv(vUv, uRes.x / uRes.y, uImgAspect)`. `noiseChunk` adds `hash`, `hash2`, `noise`, `fbm` and `gridPoint` the same way. If you hash grid points yourself, write `hash(gridPoint(i + offset))`, so neighboring cells agree on the points they share.

```ts
import { createImageEffect } from "@glimmerui/core";

const sepia = createImageEffect(el, { src: "/photo.jpg" }, {
  fragment: `
    precision highp float;
    uniform sampler2D uTex;
    uniform float uHover;
    varying vec2 vUv;
    void main() {
      vec3 c = texture2D(uTex, vUv).rgb;
      float g = dot(c, vec3(0.299, 0.587, 0.114));
      gl_FragColor = vec4(mix(vec3(g) * vec3(1.1, 0.95, 0.8), c, uHover), 1.0);
    }
  `,
  resolve: (o) => o,
  uniforms: () => ({}),
});
```

Image effects can also create extra GPU resources once with a `setup(gl, options)` hook that returns more uniforms, such as a texture. Textures returned from `setup` are freed when the effect is destroyed. `AsciiImage` uses this for its texture of characters.

## Effects on the tilt card

`createTiltEffect(el, options, fragment, extraUniforms?)` is the engine behind `TiltCard` and `HoloCard`: perspective, rounded corners, glare and the image. Build the fragment with `tiltShader({ uniforms, functions, color })`, where `color` is GLSL that adjusts `col` before it's drawn. It can read the card's own coordinates in `uv`, its rotation in `uRot` and the hover amount in `uHover`.
